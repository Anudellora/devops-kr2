# Ревизия исходного шаблона

Исходное состояние зафиксировано в первом коммите `main`. Файлы восстановлены
по опубликованному шаблону преподавателя
https://gitverse.ru/dgimatdinov/kr2-template; история GitVerse недоступна
из сети хоста, поэтому первый коммит локального репозитория не совпадает с
коммитом преподавателя.

| № | Файл и строка исходного состояния | Дефект | Последствие | Исправление |
|---|---|---|---|---|
| 1 | `Dockerfile:1` | `python:latest` | Сборка в разные дни может дать разные версии Python и сломать зависимости. | `python:3.12-slim`, уже загруженный в ПР № 7. |
| 2 | `Dockerfile:3–4` | `COPY . .` до установки зависимостей | Любое изменение `app.py` заново запускает `pip install`, удлиняя сборку. | Копировать `requirements.txt` и установить зависимости до копирования кода. |
| 3 | `Dockerfile:3`, отсутствие `.dockerignore` | В контекст и слои образа попадает `.env` с паролем. | Владелец образа может извлечь пароль даже после удаления файла в следующем слое. | Исключить `.env`, копировать только требуемые файлы. |
| 4 | `Dockerfile:5–6` | Жёстко задан порт 8000 | Вариант 2 требует порт 8002; проверка и прокси не попадут в приложение. | `EXPOSE 8002` и bind на 8002. |
| 5 | `Dockerfile:6` | Bind на `127.0.0.1` внутри контейнера | Публикация Docker направляет запрос на сетевой адрес контейнера, где Gunicorn не слушает. | Слушать `0.0.0.0` внутри контейнера; на хосте ограничить публикацию `127.0.0.1`. |
| 6 | `Dockerfile:6` | Shell-форма `CMD` | Оболочка становится PID 1 и может задерживать доставку SIGTERM Gunicorn. | Exec-форма JSON-массивом. |
| 7 | `Dockerfile:1–6` | Не задан `USER` | Веб-процесс имеет права root внутри контейнера, увеличивая последствия компрометации. | Создать пользователя `app` и переключиться на него. |
| 8 | `.env:1`, отсутствие `.gitignore` | Пароль отслеживается Git | Удаление файла новым коммитом не удалит секрет из опубликованной истории. | Удалить `.env` из ветки, добавить `.gitignore`, создать новый случайный пароль только на ВМ. |
| 9 | отсутствие `.env.example` | Нет безопасного перечня необходимых переменных | При развёртывании пароль могут записать в код или Compose. | Добавить пример с заглушкой. |
